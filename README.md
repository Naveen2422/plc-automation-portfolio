# Naveen N. — PLC Automation Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript. It is ready to deploy on Vercel without a build step.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

1. Extract this ZIP.
2. Create a GitHub repository and upload the contents of this folder (not the parent folder).
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Framework preset: **Other**. Build command: leave empty. Output directory: `.` (or leave default if Vercel detects static files).
5. Deploy. Your site will receive a `vercel.app` URL.

You can also deploy using Vercel CLI from this folder with `vercel` if you have it installed.

## Personalize before sharing

- Confirm your role, employer and dates in `index.html`.
- Replace each project placeholder with your real project screenshots.
- Add your own demo video embed IDs in the video section.
- Add sanitized project archives to `project-files/` and update the links.
- Remove any project you did not personally work on. The current project entries are editable starter examples based on the project areas discussed; they are not claims that every listed project is complete.
- Check all links and spelling on desktop and mobile before sharing with recruiters.

## Privacy and IP

Only publish files you own or are authorized to share. Do not upload employer/customer-confidential programs, drawings, credentials, network details or licensed software installers. A PDF overview, cropped screenshots and short demonstration video are often safer than sharing a full working project archive.
